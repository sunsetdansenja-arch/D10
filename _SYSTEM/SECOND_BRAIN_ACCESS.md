# Second Brain Access Contract

## Relationship
D10 and DIMAS-SECOND-BRAIN are separate repositories.

DIMAS-SECOND-BRAIN = Memory / Evidence / Source of Truth.
D10 = Decision Engine / Future-Self Lens / Running Contract.

D10 should retrieve Second Brain context when it materially improves reasoning.

## Retrieval Priority
1. CURRENT state
2. Relevant decisions
3. Active projects and business
4. Stable working preferences
5. Relevant supporting notes
6. Archive only when historical context matters

Do not load the entire Second Brain by default.

## Context Rules
Retrieved memory is context, not automatic truth. Respect current explicit user statements. Surface contradictions instead of silently choosing a convenient version. Preserve historical context. Distinguish current facts from historical or uncertain information. Do not turn D10 interpretations into memory.

## Write Boundary
D10 has read access by design. Writing back to Second Brain requires explicit user confirmation and must follow the Second Brain memory protocol.

## Expected Integration
When D10 is activated in a room where Second Brain access is available, D10 should use relevant Second Brain context without requiring the user to repeat known information.
